Threading rules (CLAUDE.md "Threading model" 1–8) and where this plan implements each:

| Rule | Implementation |
|---|---|
| 1 signals QObject owned by main thread, outlives runnable | `WorkerSignals` created in `Worker.__init__` (main thread); `WorkerRegistry` holds the `Worker` until its finished signal was handled and `run()` passed its last statement; abandoned workers are parked in `workers._ABANDONED` for the process lifetime |
| 2 `autoDelete=False` with the reason next to it | `Worker.__init__` |
| 3 no blocking `waitForDone()` on the GUI thread | `WorkerRegistry.wait_idle(timeout_s)` pumps events under a deadline; `MainWindow.closeEvent` uses it with `CLOSE_TIMEOUT_S = 15.0` |
| 4 guard flag set before cancelling, checked at the top of completion slots | `_closing` (window), `_gl_download_cancel_requested` (artifact), `_flash_cancel_requested` (flash); every completion slot starts with `if self._closing: return` |
| 5 every exit path undoes what `run()` started | `FlashWorkflow` (core, R15/R16) owns rollback + disconnect; `Worker.run` always emits `finished` in `finally` |
| 6 no connect/moveToThread/deleteLater from worker code | all `connect()` calls in `WorkerRegistry.start()` (main thread, asserted) before `pool.start()`; nothing ever `deleteLater()`s a worker |
| 7 cancel/timeout honoured inside the blocking call | the token goes into `adapter.download(...)` / `download_artifacts(...)`, and `WorkerContext.progress` raises `CancelledError` once cancel was requested |
| 8 never a lambda on a pool-thread signal | `WorkerRegistry.start()` raises `TypeError` unless every slot is a bound method of a `QObject`; tests prove it |

```python
"""Worker lifecycle tests. Every test name contains `thread` so `pytest -k thread` selects them."""
import threading
import time

import pytest
from PySide6.QtCore import QObject, QThreadPool

from wflash.core.errors import CancelledError, GitLabError
from wflash.gui import workers
from wflash.gui.workers import WorkerRegistry

pytestmark = pytest.mark.gui


class Receiver(QObject):
    """Main-thread QObject whose bound methods are the slots (never lambdas)."""

    def __init__(self):
        super().__init__()
        self.succeeded, self.failed, self.finished = [], [], []
        self.progress, self.steps = [], []
        self.slot_threads = set()
        self.registry_saw_running = []
        self.registry = None

    def on_succeeded(self, key, result):
        self.slot_threads.add(threading.get_ident())
        self.succeeded.append((key, result))

    def on_failed(self, key, exc):
        self.slot_threads.add(threading.get_ident())
        self.failed.append((key, exc))

    def on_finished(self, key):
        self.slot_threads.add(threading.get_ident())
        self.registry_saw_running.append(self.registry.is_running(key))
        self.finished.append(key)

    def on_progress(self, percent, message):
        self.slot_threads.add(threading.get_ident())
        self.progress.append((percent, message))

    def on_step(self, text):
        self.steps.append(text)


@pytest.fixture
def env(qtbot):
    pool = QThreadPool()
    registry = WorkerRegistry(pool)
    receiver = Receiver()
    receiver.registry = registry
    yield registry, receiver
    registry.cancel_all()
    assert registry.wait_idle(5.0)


def start(registry, receiver, fn, name="t"):
    return registry.start(
        name,
        fn,
        on_succeeded=receiver.on_succeeded,
        on_failed=receiver.on_failed,
        on_finished=receiver.on_finished,
        on_progress=receiver.on_progress,
        on_step=receiver.on_step,
    )


def test_thread_success_delivers_result_on_gui_thread(env, qtbot):
    registry, rx = env
    worker_threads = []

    def fn(ctx):
        worker_threads.append(threading.get_ident())
        ctx.step("S1")
        ctx.progress(50, "half")
        return 42

    key = start(registry, rx, fn, "ok")
    assert key.startswith("ok-")
    qtbot.waitUntil(lambda: rx.finished == [key], timeout=3000)
    assert rx.succeeded == [(key, 42)]
    assert rx.steps == ["S1"] and rx.progress == [(50, "half")]
    assert rx.slot_threads == {threading.get_ident()}
    assert worker_threads and worker_threads[0] != threading.get_ident()
```

```python
"""Run blocking work on a QThreadPool and report back to the GUI thread through Qt signals.

Threading model (CLAUDE.md "Threading model"; the numbers below refer to its rules):

- `core/` never sees Qt. A job receives a `WorkerContext` of plain callbacks plus a
  `CancelToken`; only `WorkerSignals` turns those into Qt signals.
- Rule 1/2: `WorkerSignals` is created in `Worker.__init__`, i.e. on the main thread, and
  is owned by the `Worker`. `WorkerRegistry` keeps the `Worker` (and so its signals)
  referenced until its `finished` signal has been handled on the main thread, and until
  `run()` has passed its last statement (see `_purge_retired`).
- Rule 6: every `connect()` happens in `WorkerRegistry.start()` on the main thread,
  before the runnable is handed to the pool. Nothing in `Worker.run()` connects,
  disconnects, moves or deletes a QObject.
- Rule 8: `WorkerRegistry.start()` refuses any slot that is not a bound method of a
  QObject (a lambda or a plain function has no thread affinity, so a queued call
  cannot be made and it would silently run on the pool thread).
- Rule 3: `wait_idle()` waits with a deadline and pumps the event loop between
  attempts. Nothing here calls `QThreadPool.waitForDone()`.
- Rule 7: `WorkerContext.progress` raises `CancelledError` once cancel was requested,
  so a blocking call that reports progress is stopped from inside.
"""
from __future__ import annotations

import itertools
import threading
import time
from dataclasses import dataclass
from typing import Any, Callable

from PySide6.QtCore import QCoreApplication, QEventLoop, QObject, QRunnable, QThread, QThreadPool, Signal

from wflash.core.cancel import CancelToken
from wflash.core.errors import CancelledError, WFlashError
from wflash.core.logging_setup import get_logger

log = get_logger("worker")

# Workers still running when their owner gave up waiting (window closed, wait timed out).
# Parked here for the rest of the process so their signals object is never deleted
# while run() can still emit (CLAUDE.md threading rule 1).
_ABANDONED: list["Worker"] = []


class WorkerSignals(QObject):
    """Signals of one Worker. Every signal carries the worker key first."""

    progress = Signal(object, str)  # percent (int | None), message
    step = Signal(str)
    succeeded = Signal(str, object)  # key, result
    failed = Signal(str, object)  # key, exception
    finished = Signal(str)  # key; always the last signal of a worker


@dataclass
class WorkerContext:
    cancel: CancelToken
    progress: Callable[[int | None, str], None]
    step: Callable[[str], None]


class Worker(QRunnable):
    def __init__(self, key: str, fn: Callable[[WorkerContext], Any]) -> None:
        super().__init__()
        # autoDelete=False: Python owns this runnable and the main thread disposes of it
        # (WorkerRegistry). With the default (True) the pool would destroy the C++ object
        # as soon as run() returns while Python still holds the wrapper and the signals,
        # which turns into a use-after-free (CLAUDE.md threading rule 2).
        self.setAutoDelete(False)
        self.key = key
        self._fn = fn
        self.signals = WorkerSignals()  # created on the main thread (rule 1, rule 6)
        self.cancel = CancelToken()
        self.done = threading.Event()  # set as the very last statement of run()

    def _progress(self, percent: int | None, message: str) -> None:
        self.signals.progress.emit(percent, message)
        # Rule 7: a cancel is honoured inside the blocking call that reports progress.
        self.cancel.raise_if_cancelled()

    def run(self) -> None:
        try:
            ctx = WorkerContext(cancel=self.cancel, progress=self._progress, step=self.signals.step.emit)
            log.debug("Worker %s started", self.key)
            try:
                result = self._fn(ctx)
            except CancelledError as exc:
                log.warning("%s cancelled", self.key)
                self.signals.failed.emit(self.key, exc)
            except WFlashError as exc:
                log.error("%s failed: %s%s", self.key, exc, f" (hint: {exc.hint})" if exc.hint else "")
                log.debug("%s traceback", self.key, exc_info=True)
                self.signals.failed.emit(self.key, exc)
            except Exception as exc:
                log.exception("%s crashed: %s", self.key, exc)
                self.signals.failed.emit(self.key, exc)
            else:
                log.debug("Worker %s finished", self.key)
                self.signals.succeeded.emit(self.key, result)
        finally:
            self.signals.finished.emit(self.key)
            self.done.set()


def _require_qobject_slot(slot: Callable[..., Any] | None, name: str) -> None:
    if slot is None:
        return
    owner = getattr(slot, "__self__", None)
    if not isinstance(owner, QObject):
        raise TypeError(
            f"{name} must be a bound method of a QObject living on the GUI thread, got {slot!r} "
            "(CLAUDE.md threading rule 8: never connect a lambda or plain function to a pool-thread signal)"
        )


class WorkerRegistry(QObject):
    """Main-thread owner of every running Worker of one window."""

    def __init__(self, pool: QThreadPool, parent: QObject | None = None) -> None:
        super().__init__(parent)
        self._pool = pool
        self._running: dict[str, Worker] = {}
        self._retired: list[Worker] = []
        self._counter = itertools.count(1)

    def start(
        self,
        name: str,
        fn: Callable[[WorkerContext], Any],
        *,
        on_succeeded: Callable[[str, Any], None],
        on_failed: Callable[[str, Any], None],
        on_finished: Callable[[str], None] | None = None,
        on_progress: Callable[[Any, str], None] | None = None,
        on_step: Callable[[str], None] | None = None,
    ) -> str:
        app = QCoreApplication.instance()
        if app is None or QThread.currentThread() is not app.thread():
            raise RuntimeError("WorkerRegistry.start() must be called on the GUI thread")
        for slot, slot_name in (
            (on_succeeded, "on_succeeded"),
            (on_failed, "on_failed"),
            (on_finished, "on_finished"),
            (on_progress, "on_progress"),
            (on_step, "on_step"),
        ):
            _require_qobject_slot(slot, slot_name)
        self._purge_retired()
        key = f"{name}-{next(self._counter)}"
        worker = Worker(key, fn)
        signals = worker.signals
        signals.succeeded.connect(on_succeeded)
        signals.failed.connect(on_failed)
        if on_progress is not None:
            signals.progress.connect(on_progress)
        if on_step is not None:
            signals.step.connect(on_step)
        # Connected before the owner's finished slot, so that slot already sees the worker
        # as no longer running when it recomputes button states (the registry still keeps
        # the Worker referenced in `_retired`).
        signals.finished.connect(self._on_worker_finished)
        if on_finished is not None:
            signals.finished.connect(on_finished)
        self._running[key] = worker
        self._pool.start(worker)
        return key

    def _on_worker_finished(self, key: str) -> None:
        worker = self._running.pop(key, None)
        # Workers retired earlier: their owners' finished slots were queued before this
        # event and have run. The one finishing now is kept: its owner slot is still queued.
        self._purge_retired()
        if worker is not None:
            self._retired.append(worker)

    def _purge_retired(self) -> None:
        # Drop our reference only once run() has passed its last statement; the finished
        # signal is emitted a few statements before that.
        self._retired = [w for w in self._retired if not w.done.is_set()]

    def worker(self, key: str | None) -> Worker | None:
        return self._running.get(key) if key else None

    def is_running(self, key: str | None) -> bool:
        return bool(key) and key in self._running

    def running_keys(self) -> list[str]:
        return list(self._running)

    def has_running(self, prefix: str = "") -> bool:
        return any(key.startswith(prefix) for key in self._running)

    def cancel(self, key: str | None) -> None:
        worker = self.worker(key)
        if worker is not None:
            worker.cancel.cancel()

    def cancel_all(self) -> None:
        for worker in self._running.values():
            worker.cancel.cancel()

    def wait_idle(self, timeout_s: float) -> bool:
        """Pump events until every finished signal was handled, or the deadline passes.

        Rule 3: never block the GUI loop on the pool — the workers' queued signals can only
        be delivered while this loop runs.
        """
        deadline = time.monotonic() + timeout_s
        while self._running:
            if time.monotonic() >= deadline:
                return False
            QCoreApplication.processEvents(QEventLoop.ProcessEventsFlag.AllEvents, 50)
            pending = next(iter(self._running.values()), None)
            if pending is not None:
                pending.done.wait(0.01)
        return True

    def abandon_running(self) -> list[str]:
        """Park still-running workers for the rest of the process; return their keys."""
        keys = list(self._running)
        for key in keys:
            worker = self._running.pop(key)
            log.warning("Worker %s did not stop in time; abandoning it", key)
            _ABANDONED.append(worker)
        _ABANDONED.extend(self._retired)
        self._retired = []
        return keys
```

```python
def without_uic_version(text: str) -> str:
    # The header names the uic version; a PySide6 upgrade alone must not fail the build.
    return "\n".join(line for line in text.splitlines() if "User Interface Compiler version" not in line)


def uic_executable() -> str | None:
    folder = Path(sys.executable).parent
    for candidate in (folder / "pyside6-uic", folder / "pyside6-uic.exe"):
        if candidate.is_file():
            return str(candidate)
    return shutil.which("pyside6-uic")

    assert names, f"no widgets parsed from {ui_name}"
    bad = [n for n in names if n not in TOP_LEVEL and not (n and MEANINGFUL.match(n))]
    assert bad == [], f"Designer default or unclear names in {ui_name}: {bad}"
    assert len(names) == len(set(names)), "duplicate object names"
```

```python
def artifact_zip_bytes(files: dict[str, bytes] = ARTIFACT_FILES, padding: int = 64 * 1024) -> bytes:
    """Zip of the artifact. `padding` bytes of stored data make the stream span many chunks."""
    buf = io.BytesIO()
    with zipfile.ZipFile(buf, "w", zipfile.ZIP_STORED) as zf:
        for name, data in files.items():
            zf.writestr(name, data)
        if padding:
            zf.writestr("out/padding.bin", b"\0" * padding)
    return buf.getvalue()


def make_artifact_tree(root: Path, files: dict[str, bytes] = ARTIFACT_FILES) -> Path:
    for rel, data in files.items():
        path = root / rel
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_bytes(data)
    return root


def write_profiles(folder: Path, download_s: int | None = None) -> Path:
    folder.mkdir(parents=True, exist_ok=True)
    text = EXAMPLE_PROFILE.read_text(encoding="utf-8")
    if download_s is not None:
        text = text.replace("download_s: 600", f"download_s: {download_s}")
    (folder / "saf.yaml").write_text(text, encoding="utf-8")
    return folder


class _SlowRaw(io.BytesIO):
    """Response body that hands out small chunks with a delay, like a slow network."""

    def __init__(self, data: bytes, chunk: int, delay_s: float) -> None:
        super().__init__(data)
        self._chunk = chunk
        self._delay_s = delay_s

    def read(self, size: int | None = -1) -> bytes:
        if self._delay_s:
            time.sleep(self._delay_s)
        limit = self._chunk if size is None or size < 0 else min(size, self._chunk)
        return super().read(limit)


class FakeGitLabSession:
    """Answers the GitLab REST v4 calls GitLabClient makes. Thread-safe."""

    def __init__(
        self,
        delay_s: float = 0.0,
        fail_status: int | None = None,
        connection_error: bool = False,
        chunk_delay_s: float = 0.0,
    ) -> None:
        self.headers = CaseInsensitiveDict()
        self.delay_s = delay_s
        self.fail_status = fail_status
        self.connection_error = connection_error
        self.chunk_delay_s = chunk_delay_s
        self.zip_bytes = artifact_zip_bytes()
        self.calls: list[str] = []
        self._lock = threading.Lock()

    def count(self, suffix: str) -> int:
        with self._lock:
            return sum(1 for path in self.calls if path.endswith(suffix))

    def get(self, url, params=None, timeout=None, verify=None, stream=False):
        path = unquote(urlparse(url).path).removeprefix("/api/v4")
        with self._lock:
            self.calls.append(path)
        if self.delay_s:
            time.sleep(self.delay_s)  # like a real request: not interruptible by cancel
        if self.connection_error:
            raise requests.exceptions.ConnectionError(f"Failed to establish a new connection to {url}")
        if self.fail_status is not None:
            return self._response(self.fail_status, {"message": f"{self.fail_status} error"})
        if path == f"/projects/{PROJECT}":
            return self._response(200, {"id": PROJECT_ID})
        if path == f"/projects/{PROJECT_ID}/repository/branches":
            return self._response(200, [{"name": "main"}])
        if path == f"/projects/{PROJECT_ID}/repository/tags":
            return self._response(200, [{"name": "v1.0"}])
        if path == f"/projects/{PROJECT_ID}/pipelines":
            ref = (params or {}).get("ref", "main")
            return self._response(
                200,
                [{"id": PIPELINE_ID, "ref": ref, "status": "success", "sha": "abcdef1234567",
                  "created_at": "2026-10-01T10:00:00Z"}],
            )
        if path == f"/projects/{PROJECT_ID}/pipelines/{PIPELINE_ID}/jobs":
            return self._response(
                200,
                [{"id": JOB_ID, "name": "build_app", "stage": "build", "status": "success",
                  "finished_at": "2026-10-01T10:05:00Z", "artifacts": [{"file_type": "archive"}]},
                 {"id": 8, "name": "lint", "stage": "test", "status": "success", "artifacts": []}],
            )
        if path == f"/projects/{PROJECT_ID}/jobs/{JOB_ID}/artifacts":
            resp = requests.Response()
            resp.status_code = 200
            resp.url = url
            resp.headers = CaseInsensitiveDict({"Content-Length": str(len(self.zip_bytes))})
            resp.raw = _SlowRaw(self.zip_bytes, 4096, self.chunk_delay_s)
            return resp
        return self._response(404, {"message": "404 Not Found"})

    @staticmethod
    def _response(status: int, payload) -> requests.Response:
        resp = requests.Response()
        resp.status_code = status
        resp._content = json.dumps(payload).encode()
        resp.headers = CaseInsensitiveDict({"Content-Type": "application/json"})
        return resp
```

```python
"""Log panel mixin: coloured, filterable view of the `wflash` log, Copy/Clear, debug bundle export.

Host contract (provided by MainWindow): `self.ui` (Ui_MainWindow), `self.ctx` (DebugContext),
`self.log_file` (Path | None), `self.flash_active()` (FlashMixin), `self.statusBar()`.
"""
from __future__ import annotations

import logging
from collections import deque
from pathlib import Path

from PySide6.QtCore import QObject, Signal
from PySide6.QtGui import QColor, QFontDatabase, QGuiApplication, QTextCharFormat, QTextCursor
from PySide6.QtWidgets import QFileDialog, QMessageBox

from wflash.core.debug_bundle import create_debug_bundle
from wflash.core.logging_setup import LOGGER_NAME, RedactingFormatter, get_logger

log = get_logger("ui.log")

PANEL_FORMAT = "%(asctime)s %(levelname)-7s %(name)s: %(message)s"
MAX_RECORDS = 20000
LEVEL_COLORS = {
    logging.DEBUG: "#8a8a8a",
    logging.WARNING: "#c77700",
    logging.ERROR: "#d32f2f",
    logging.CRITICAL: "#d32f2f",
}


class LogEmitter(QObject):
    """Carries formatted records to the GUI thread. Created on the main thread."""

    record = Signal(int, str)


class QtLogHandler(logging.Handler):
    """logging.Handler usable from any thread: it only emits a queued Qt signal."""

    def __init__(self) -> None:
        super().__init__(logging.DEBUG)
        self.emitter = LogEmitter()
        self.setFormatter(RedactingFormatter(PANEL_FORMAT, "%H:%M:%S"))

    def emit(self, record: logging.LogRecord) -> None:
        try:
            text = self.format(record)
        except Exception:
            self.handleError(record)
            return
        self.emitter.record.emit(record.levelno, text)


class LogPanelMixin:
    def _init_log_panel(self) -> None:
        self._log_records: deque[tuple[int, str]] = deque(maxlen=MAX_RECORDS)
        # The system fixed-pitch font differs per OS; Designer cannot express "system font".
        self.ui.plainTextEdit_log.setFont(QFontDatabase.systemFont(QFontDatabase.SystemFont.FixedFont))
        self.log_handler = QtLogHandler()
        # Bound method of this QMainWindow: queued onto the GUI thread (threading rule 8).
        self.log_handler.emitter.record.connect(self._append_log_record)
        logger = logging.getLogger(LOGGER_NAME)
        if logger.level == logging.NOTSET:
            logger.setLevel(logging.DEBUG)  # main() does this via setup_logging; tests may not
        logger.addHandler(self.log_handler)
        self.ui.comboBox_logLevel.currentIndexChanged.connect(self._refilter_log)
        self.ui.pushButton_copyLog.clicked.connect(self.copy_log)
        self.ui.pushButton_clearLog.clicked.connect(self.clear_log)
        self.ui.pushButton_exportBundle.clicked.connect(self._on_export_bundle_clicked)

    def _detach_log_panel(self) -> None:
        logging.getLogger(LOGGER_NAME).removeHandler(self.log_handler)

    # -- view -----------------------------------------------------------------------
    def log_min_level(self) -> int:
        return logging.getLevelNamesMapping()[self.ui.comboBox_logLevel.currentText()]

    def _append_log_record(self, level: int, text: str) -> None:
        self._log_records.append((level, text))
        if level >= self.log_min_level():
            self._write_log_line(level, text)
        if level >= logging.ERROR:
            self.statusBar().showMessage("Error — see the log panel", 10000)

    def _write_log_line(self, level: int, text: str) -> None:
        view = self.ui.plainTextEdit_log
        cursor = view.textCursor()
        cursor.movePosition(QTextCursor.MoveOperation.End)
        if not view.document().isEmpty():
            cursor.insertBlock()
        fmt = QTextCharFormat()
        color = LEVEL_COLORS.get(level)
        if color:
            fmt.setForeground(QColor(color))
        cursor.insertText(text, fmt)
        view.setTextCursor(cursor)
        view.ensureCursorVisible()  # keeps the newest line, and so the newest error, in view

    def _refilter_log(self, *_args) -> None:
        self.ui.plainTextEdit_log.clear()
        minimum = self.log_min_level()
        for level, text in self._log_records:
            if level >= minimum:
                self._write_log_line(level, text)

    def log_visible_text(self) -> str:
        return self.ui.plainTextEdit_log.toPlainText()

    def copy_log(self) -> None:
        QGuiApplication.clipboard().setText(self.log_visible_text())

    def clear_log(self) -> None:
        self._log_records.clear()
        self.ui.plainTextEdit_log.clear()

    # -- debug bundle ---------------------------------------------------------------
    def export_bundle(self, dest_dir: Path) -> Path:
        # DebugContext is written by the flash worker; it is only read when no flash runs.
        if self.flash_active():
            raise RuntimeError("Cannot export a debug bundle while a flash is running")
        path = create_debug_bundle(self.ctx, dest_dir, self.log_file)
        log.info("Debug bundle saved: %s", path)
        return path

    def _on_export_bundle_clicked(self) -> None:
        if self.flash_active():
            return
        desktop = Path.home() / "Desktop"
        start = desktop if desktop.is_dir() else Path.home()
        directory = QFileDialog.getExistingDirectory(self, "Save debug bundle to", str(start))
        if not directory:
            return
        try:
            path = self.export_bundle(Path(directory))
        except OSError as exc:
            log.error("Cannot write debug bundle: %s", exc)
            QMessageBox.critical(self, "WFlash", f"Cannot write the debug bundle:\n{exc}")
            return
        QMessageBox.information(self, "Debug bundle", f"Saved:\n{path}\n\nSend this file for debugging.")
```

```python
"""Mapping table mixin: which artifact file goes to which winIDEA entry.

A row whose pattern matched zero or several files is red and has no file selected; the
user must choose one (spec §5). Nothing here ever picks a file on the user's behalf.

Host contract: `self.ui`, `self.profile` (Profile | None), `self._update_flash_controls()`.
The rows are dynamic content, so they are built here; the table, its columns and its
header live in main_window.ui.
"""
from __future__ import annotations

from functools import partial
from pathlib import Path

from PySide6.QtWidgets import QComboBox, QHeaderView, QTableWidgetItem

from wflash.core.file_matcher import MappingRow, build_mapping, candidates_for_kind
from wflash.core.logging_setup import get_logger

log = get_logger("ui.mapping")

FILE_COLUMN = 3
NONE_TEXT = "-- select file --"
MISSING_STYLE = "QComboBox { background-color: #ffcdd2; color: black; }"


class MappingTableMixin:
    def _init_mapping_table(self) -> None:
        self._mapping_rows: list[MappingRow] = []
        self.artifact_root: Path | None = None
        header = self.ui.tableWidget_mapping.horizontalHeader()
        header.setSectionResizeMode(FILE_COLUMN, QHeaderView.ResizeMode.Stretch)

    def on_artifact_ready(self, path: Path, label: str) -> None:
        """Build the mapping for a freshly downloaded (or cached) artifact."""
        if self.profile is None:
            return
        rows = build_mapping(self.profile, path)
        self.set_mapping_rows(rows, path)
        self.ui.label_artifact.setText(f"{label}\n{path}")
        for row in rows:
            if row.ok:
                log.info("%s '%s' -> %s", row.kind, row.target, row.selected.relative_to(path).as_posix())
            else:
                log.warning(
                    "%s '%s': %d file(s) match '%s'; choose a file manually",
                    row.kind, row.target, len(row.candidates), row.pattern,
                )

    def set_mapping_rows(self, rows: list[MappingRow], root: Path) -> None:
        table = self.ui.tableWidget_mapping
        self._mapping_rows = rows
        self.artifact_root = root
        table.setRowCount(len(rows))
        for index, row in enumerate(rows):
            kind_text = "Program (.s3)" if row.kind == "program" else "Symbols (.elf)"
            for column, text in enumerate((kind_text, row.target, row.pattern)):
                table.setItem(index, column, QTableWidgetItem(text))
            combo = QComboBox()
            combo.addItem(NONE_TEXT, None)
            options = row.candidates or candidates_for_kind(root, row.kind)
            for option in options:
                combo.addItem(option.relative_to(root).as_posix(), str(option))
            if row.selected is not None:
                combo.setCurrentIndex(options.index(row.selected) + 1)
            # GUI-thread signal from a GUI-thread widget: a partial is safe here. The
            # lambda/partial ban (threading rule 8) is about signals emitted from pool threads.
            combo.currentIndexChanged.connect(partial(self._on_mapping_choice, index))
            table.setCellWidget(index, FILE_COLUMN, combo)
            self._paint_mapping_row(index)
        table.resizeColumnsToContents()
        self._update_flash_controls()

    def clear_mapping(self) -> None:
        self._mapping_rows = []
        self.artifact_root = None
        self.ui.tableWidget_mapping.setRowCount(0)
        self.ui.label_artifact.setText("No artifact loaded")
        self._update_flash_controls()

    def mapping_combo(self, index: int) -> QComboBox:
        return self.ui.tableWidget_mapping.cellWidget(index, FILE_COLUMN)

    def _on_mapping_choice(self, index: int, _combo_index: int) -> None:
        data = self.mapping_combo(index).currentData()
        self._mapping_rows[index].selected = Path(data) if data else None
        self._paint_mapping_row(index)
        self._update_flash_controls()

    def _paint_mapping_row(self, index: int) -> None:
        self.mapping_combo(index).setStyleSheet("" if self._mapping_rows[index].ok else MISSING_STYLE)

    def mapping_rows(self) -> list[MappingRow]:
        return list(self._mapping_rows)

    def mapping_complete(self) -> bool:
        return bool(self._mapping_rows) and all(row.ok for row in self._mapping_rows)
```

```python
network. List results carry the generation they were requested for, so a result that

(WorkerRegistry), `self._closing`, `self._client_factory`, `self.show_error()`,

def default_client_factory(settings: AppSettings) -> GitLabClient:
    """Called on a worker thread: builds a client from the settings and the keyring token."""
    token = get_token(settings.gitlab_url)
    if not settings.gitlab_url or not token:
        raise GitLabError(
            "GitLab URL or token is not configured",
            hint="Open Settings… and enter the GitLab URL and a Personal Access Token (scope read_api).",
        )

        self._gl_download_key: str | None = None

        self.ui.progressBar_artifact.setValue(0)
        self.ui.pushButton_refreshRefs.clicked.connect(self.refresh_gitlab)
        self.ui.comboBox_ref.currentIndexChanged.connect(self._on_ref_changed)
        self.ui.listWidget_pipelines.currentItemChanged.connect(self._on_pipeline_changed)
        self.ui.listWidget_jobs.currentItemChanged.connect(self._update_gitlab_controls)
        self.ui.pushButton_downloadArtifact.clicked.connect(self.download_selected_artifact)
        self.ui.pushButton_cancelArtifact.clicked.connect(self.cancel_artifact_download)
        self._update_gitlab_controls()

    # -- state ----------------------------------------------------------------------
    def gitlab_busy(self) -> bool:
        return self._workers.has_running("gitlab-")

    def artifact_downloading(self) -> bool:
        return self._workers.is_running(self._gl_download_key)

    def _update_gitlab_controls(self, *_args) -> None:
        downloading = self.artifact_downloading()
        self.ui.pushButton_refreshRefs.setEnabled(self.profile is not None and not downloading)
        self.ui.pushButton_downloadArtifact.setEnabled(
            self.ui.listWidget_jobs.currentItem() is not None and not downloading
        )
        self.ui.pushButton_cancelArtifact.setEnabled(downloading)

    def _start_gitlab(self, name: str, fn: Callable[[WorkerContext], object], on_succeeded, on_progress=None) -> str:
        return self._workers.start(
            f"gitlab-{name}",
            fn,
            on_succeeded=on_succeeded,
            on_failed=self._on_gitlab_failed,
            on_finished=self._on_gitlab_finished,
            on_progress=on_progress,
        )

    def _settings_snapshot(self) -> AppSettings:
        # Workers get their own copy; the GUI thread may keep editing self.settings.
        return dataclasses.replace(self.settings)

    # -- profile ----------------------------------------------------------------------
    def set_gitlab_profile(self, profile: Profile | None) -> None:
        self.cancel_artifact_download()
        self._gl_generation += 1
        self._gl_profile_generation += 1
        self._gl_project_id = None
        if profile is None:
            self.ui.label_project.setText("No profile")
        else:
            self.ui.label_project.setText(
                f"Project: {profile.gitlab.project}  (jobs: {profile.gitlab.job_filter})"
            )
        self.ui.comboBox_ref.blockSignals(True)
        self.ui.comboBox_ref.clear()
        self.ui.comboBox_ref.blockSignals(False)
        self.ui.listWidget_pipelines.clear()
        self.ui.listWidget_jobs.clear()
        self._update_gitlab_controls()

    # -- browsing ---------------------------------------------------------------------
    def refresh_gitlab(self, *_args) -> None:
        if self.profile is None or self._closing or self.flash_active():
            return
        self._gl_generation += 1
        generation = self._gl_generation
        project = self.profile.gitlab.project
        factory, settings = self._client_factory, self._settings_snapshot()

        def job(ctx: WorkerContext):
            client = factory(settings)
            project_id = client.get_project_id(project)
            return generation, project_id, client.list_refs(project_id)

        self._start_gitlab("refs", job, self._on_refs_loaded)

    def _on_refs_loaded(self, _key: str, result) -> None:
        if self._closing:
            return
        generation, project_id, refs = result
        if generation != self._gl_generation:
            return
        self._gl_project_id = project_id
        combo = self.ui.comboBox_ref
        combo.blockSignals(True)
        combo.clear()
        for ref in refs:
            combo.addItem(ref.name + (" (tag)" if ref.kind == "tag" else ""), ref.name)
        combo.blockSignals(False)
        log.info("Loaded %d branches/tags", len(refs))
        self._on_ref_changed()

    def _on_ref_changed(self, *_args) -> None:
        self.ui.listWidget_pipelines.clear()
        self.ui.listWidget_jobs.clear()
        ref = self.ui.comboBox_ref.currentData()
        if ref is None or self._gl_project_id is None or self._closing or self.flash_active():
            return
        generation, project_id = self._gl_generation, self._gl_project_id
        factory, settings = self._client_factory, self._settings_snapshot()

        def job(ctx: WorkerContext):
            client = factory(settings)
            return generation, ref, client.list_pipelines(project_id, ref)

        self._start_gitlab("pipelines", job, self._on_pipelines_loaded)

    def _on_pipelines_loaded(self, _key: str, result) -> None:
        if self._closing:
            return
        generation, ref, pipelines = result
        if generation != self._gl_generation or ref != self.ui.comboBox_ref.currentData():
            return
        self.ui.listWidget_pipelines.clear()
        for p in pipelines:
            created = p.created_at[:16].replace("T", " ")
            item = QListWidgetItem(f"#{p.id}   {p.status:<9} {created}   {p.sha[:8]}")
            item.setData(ROLE, p.id)
            self.ui.listWidget_pipelines.addItem(item)

    def _on_pipeline_changed(self, *_args) -> None:
        self.ui.listWidget_jobs.clear()
        current = self.ui.listWidget_pipelines.currentItem()
        if (
            current is None
            or self._gl_project_id is None
            or self.profile is None
            or self._closing
            or self.flash_active()
        ):
            self._update_gitlab_controls()
            return
        generation, project_id = self._gl_generation, self._gl_project_id
        pipeline_id = current.data(ROLE)
        job_filter = self.profile.gitlab.job_filter
        factory, settings = self._client_factory, self._settings_snapshot()

        def job(ctx: WorkerContext):
            client = factory(settings)
            return generation, pipeline_id, client.list_jobs(project_id, pipeline_id, job_filter)

        self._start_gitlab("jobs", job, self._on_jobs_loaded)

    def _on_jobs_loaded(self, _key: str, result) -> None:
        if self._closing:
            return
        generation, pipeline_id, jobs = result
        current = self.ui.listWidget_pipelines.currentItem()
        if generation != self._gl_generation or current is None or current.data(ROLE) != pipeline_id:
            return
        self.ui.listWidget_jobs.clear()
        for j in jobs:
            item = QListWidgetItem(f"{j.name}   [{j.stage}]   {j.status}")
            item.setData(ROLE, {"id": j.id, "name": j.name})
            self.ui.listWidget_jobs.addItem(item)
        if not jobs:
            log.warning("Pipeline #%s has no jobs with artifacts matching the profile filter", pipeline_id)
        self._update_gitlab_controls()

    # -- download ---------------------------------------------------------------------
    def download_selected_artifact(self, *_args) -> None:
        item = self.ui.listWidget_jobs.currentItem()
        if (
            item is None
            or self._gl_project_id is None
            or self.profile is None
            or self.artifact_downloading()  # a second click while downloading is refused
            or self.flash_active()
            or self._closing
        ):
            return
        job_info = item.data(ROLE)
        job_id, job_name = job_info["id"], job_info["name"]
        project_id, generation = self._gl_project_id, self._gl_profile_generation
        label = f"{self.profile.gitlab.project}  job #{job_id} ({job_name})"
        factory, settings = self._client_factory, self._settings_snapshot()
        cache_root, max_jobs = settings.resolved_cache_dir(), settings.max_cached_jobs

        def job(ctx: WorkerContext):
            cache = ArtifactCache(cache_root, max_jobs)
            cached = cache.get(project_id, job_id)
            if cached is not None:
                log.info("Using cached artifact for job #%s: %s", job_id, cached)
                return generation, label, cached
            client = factory(settings)

            def on_bytes(done: int, total: int) -> None:
                ctx.progress(int(done * 100 / total) if total else None, f"{done / 1e6:.1f} MB")

            with tempfile.TemporaryDirectory(prefix="wflash_dl_") as tmp:
                zip_path = client.download_artifacts(project_id, job_id, Path(tmp), on_bytes, ctx.cancel)
                ctx.progress(None, "Extracting")
                return generation, label, cache.store_zip(project_id, job_id, zip_path)

        self._gl_download_cancel_requested = False
        self.ui.progressBar_artifact.setRange(0, 100)
        self.ui.progressBar_artifact.setValue(0)
        self.ui.progressBar_artifact.setFormat("%p%")
        self._gl_download_key = self._start_gitlab(
            "download", job, self._on_artifact_downloaded, on_progress=self._on_artifact_progress
        )
        self._update_gitlab_controls()
        self._update_flash_controls()

    def cancel_artifact_download(self, *_args) -> None:
        if not self.artifact_downloading():
            return
        # Threading rule 4: the guard is set before cancelling, so a completion already
        # queued is dropped by _on_artifact_downloaded instead of loading the artifact.
        self._gl_download_cancel_requested = True
        log.warning("Artifact download cancel requested")
        self._workers.cancel(self._gl_download_key)

    def _on_artifact_progress(self, percent, message: str) -> None:
        if self._closing:
            return
        bar = self.ui.progressBar_artifact
        if percent is None:
            bar.setRange(0, 0)
        else:
            bar.setRange(0, 100)
            bar.setValue(percent)
        bar.setFormat(message)

    def _on_artifact_downloaded(self, _key: str, result) -> None:
        if self._closing or self._gl_download_cancel_requested:
            log.info("Artifact download completed after cancel; not loading it")
            return
        generation, label, path = result
        if generation != self._gl_profile_generation:
            log.info("Profile changed during download; not loading %s", label)
            return
        bar = self.ui.progressBar_artifact
        bar.setRange(0, 100)
        bar.setValue(100)
        bar.setFormat("Ready")
        self.on_artifact_ready(path, label)

    def _on_gitlab_failed(self, key: str, exc: BaseException) -> None:
        if self._closing:
            return
        if key == self._gl_download_key:
            self.ui.progressBar_artifact.setRange(0, 100)
            self.ui.progressBar_artifact.setValue(0)
            self.ui.progressBar_artifact.setFormat("Cancelled" if isinstance(exc, CancelledError) else "Failed")
        if isinstance(exc, CancelledError):
            return
        self.ctx.add_error(exc)  # no flash runs while a GitLab worker exists
        self.show_error(exc)

    def _on_gitlab_finished(self, key: str) -> None:
        if key == self._gl_download_key:
            self._gl_download_key = None
        if self._closing:
            return
        self._update_gitlab_controls()
        self._update_flash_controls()
```

```python
"""Flash mixin: winIDEA instance list, Flash/Cancel, step and progress display, post-flash state.

The flash runs `FlashWorkflow` (core) in one worker named "flash". The workflow already
guarantees the rollback (Approach A); this mixin only has to start it, honour Cancel, and
show the outcome — including a failed rollback, which the user must never miss.

Host contract: `self.ui`, `self.adapter`, `self.profile`, `self.ctx`, `self._workers`,
`self._closing`, `self.show_error()`, `self.statusBar()`, `self.mapping_rows()` and
`self.mapping_complete()` (MappingTableMixin), `self.gitlab_busy()` (GitlabBrowserMixin).
"""
from __future__ import annotations

import dataclasses

from wflash.core.errors import CancelledError, WinIDEAError
from wflash.core.flash_workflow import FlashRequest, FlashWorkflow, Step
from wflash.core.logging_setup import get_logger
from wflash.core.winidea_adapter import InstanceInfo, WinIDEAAdapter
from wflash.gui.workers import WorkerContext

log = get_logger("ui.flash")


def safe_list_instances(adapter: WinIDEAAdapter) -> list[InstanceInfo]:
    """No winIDEA, no running instance and no probe are normal states, never exceptions."""
    try:
        return list(adapter.list_instances())
    except Exception as exc:
        log.warning("Listing winIDEA instances failed: %s", exc, exc_info=True)
        return []


def instance_data(info: InstanceInfo) -> dict:
    """What the instance combo stores; read back with currentData(), never from the text."""
    return {"instance_id": info.instance_id, "workspace": info.workspace, "tcp_port": info.tcp_port}


class FlashMixin:
    def _init_flash(self) -> None:
        self._flash_key: str | None = None
        self._flash_cancel_requested = False
        self._flash_error_during_close: BaseException | None = None
        self._instances_key: str | None = None
        self.ui.progressBar_flash.setRange(0, 100)
        self.ui.progressBar_flash.setValue(0)
        self.ui.pushButton_flash.clicked.connect(self.start_flash)
        self.ui.pushButton_cancelFlash.clicked.connect(self.cancel_flash)
        self.ui.pushButton_refreshInstances.clicked.connect(self.refresh_instances)
        self.ui.comboBox_instance.currentIndexChanged.connect(self._update_flash_controls)
        self.ui.checkBox_reset.toggled.connect(self._update_flash_controls)

    # -- state ------------------------------------------------------------------------
    def flash_active(self) -> bool:
        return self._workers.is_running(self._flash_key)

    def selected_instance(self) -> dict | None:
        data = self.ui.comboBox_instance.currentData()
        return data if isinstance(data, dict) else None

    def _update_flash_controls(self, *_args) -> None:
        flashing = self.flash_active()
        can_flash = (
            not flashing
            and not self._closing
            and not self.gitlab_busy()
            and self.profile is not None
            and self.mapping_complete()
            and self.selected_instance() is not None
        )
        self.ui.pushButton_flash.setEnabled(can_flash)
        self.ui.pushButton_cancelFlash.setEnabled(flashing)
        for widget in (
            self.ui.comboBox_profile,
            self.ui.pushButton_reloadProfiles,
            self.ui.pushButton_settings,
            self.ui.groupBox_gitlab,
            self.ui.tableWidget_mapping,
            self.ui.comboBox_instance,
            self.ui.pushButton_refreshInstances,
            self.ui.checkBox_reset,
            self.ui.pushButton_exportBundle,
        ):
            widget.setEnabled(not flashing)
        self.ui.checkBox_run.setEnabled(not flashing and self.ui.checkBox_reset.isChecked())

    # -- instances --------------------------------------------------------------------
    def refresh_instances(self, *_args) -> None:
        if self._workers.is_running(self._instances_key) or self.flash_active() or self._closing:
            return
        adapter = self.adapter

        def job(ctx: WorkerContext) -> list[InstanceInfo]:
            return safe_list_instances(adapter)

        self._instances_key = self._workers.start(
            "winidea-instances", job, on_succeeded=self._on_instances_loaded, on_failed=self._on_instances_failed
        )

    def _on_instances_loaded(self, _key: str, instances: list[InstanceInfo]) -> None:
        if self._closing:
            return
        combo = self.ui.comboBox_instance
        previous = self.selected_instance()
        combo.blockSignals(True)
        combo.clear()
        for info in instances:
            combo.addItem(info.label(), instance_data(info))
        if previous is not None:
            for index in range(combo.count()):
                if combo.itemData(index)["instance_id"] == previous["instance_id"]:
                    combo.setCurrentIndex(index)
        combo.blockSignals(False)
        if instances:
            log.info("Found %d winIDEA instance(s)", len(instances))
        else:
            log.warning("No running winIDEA instance found. Open winIDEA with the SAF85xx workspace and click Refresh.")
        self._update_flash_controls()

    def _on_instances_failed(self, _key: str, exc: BaseException) -> None:
        # safe_list_instances never raises; this only catches a bug in the job itself.
        if self._closing:
            return
        log.error("Instance refresh failed: %s", exc)

    # -- flash ------------------------------------------------------------------------
    def start_flash(self, *_args) -> None:
        if self.flash_active() or self._closing or not self.ui.pushButton_flash.isEnabled():
            return
        instance = self.selected_instance()
        if instance is None:
            self.show_error(WinIDEAError("No winIDEA instance selected"))
            return
        request = FlashRequest(
            instance_id=instance["instance_id"],
            # Copies: the worker must not share mutable rows with the table.
            mapping=[dataclasses.replace(row) for row in self.mapping_rows()],
            reset=self.ui.checkBox_reset.isChecked(),
            run=self.ui.checkBox_reset.isChecked() and self.ui.checkBox_run.isChecked(),
            timeout_s=self.profile.timeouts.download_s,
        )
        adapter, debug_ctx = self.adapter, self.ctx

        def job(wctx: WorkerContext) -> None:
            def on_step(step: Step) -> None:
                wctx.step(step.value)

            FlashWorkflow(adapter, debug_ctx, on_step=on_step, on_progress=wctx.progress).run(request, wctx.cancel)

        self._flash_cancel_requested = False
        self.ui.label_rollbackWarning.setVisible(False)
        self.ui.label_step.setText("Starting")
        self.ui.progressBar_flash.setRange(0, 100)
        self.ui.progressBar_flash.setValue(0)
        self.ui.progressBar_flash.setFormat("%p%")
        log.info("Flash requested on %s (%d file(s))", instance["instance_id"], len(request.mapping))
        self._flash_key = self._workers.start(
            "flash",
            job,
            on_succeeded=self._on_flash_succeeded,
            on_failed=self._on_flash_failed,
            on_finished=self._on_flash_finished,
            on_progress=self._on_flash_progress,
            on_step=self._on_flash_step,
        )
        self._update_flash_controls()

    def cancel_flash(self, *_args) -> None:
        if not self.flash_active():
            return
        # Guard first (threading rule 4), then the token the workflow checks inside download().
        self._flash_cancel_requested = True
        log.warning("Flash cancel requested; the workspace paths will be restored")
        self.ui.label_step.setText("Cancelling")
        self._workers.cancel(self._flash_key)

    def _on_flash_step(self, text: str) -> None:
        if self._closing:
            return
        if self._flash_cancel_requested and text != Step.ROLLBACK.value:
            return  # keep "Cancelling" visible until the workflow reports the rollback
        self.ui.label_step.setText(text)

    def _on_flash_progress(self, percent, message: str) -> None:
        if self._closing:
            return
        bar = self.ui.progressBar_flash
        if percent is None:
            bar.setRange(0, 0)
            bar.setFormat(message)
        else:
            bar.setRange(0, 100)
            bar.setValue(percent)
            bar.setFormat(f"%p%  {message}")

    def _on_flash_succeeded(self, _key: str, _result) -> None:
        if self._closing:
            return
        if self._flash_cancel_requested:
            log.warning("The flash completed before the cancel took effect")
        self.ui.label_step.setText(Step.DONE.value)
        self.ui.progressBar_flash.setRange(0, 100)
        self.ui.progressBar_flash.setValue(100)
        log.info("Flash completed successfully")
        self.statusBar().showMessage("Flash completed", 10000)

    def _on_flash_failed(self, _key: str, exc: BaseException) -> None:
        if self._closing:
            # No dialogs while closing; closeEvent reports a failed rollback after the wait.
            self._flash_error_during_close = exc
            return
        rollback_failed = getattr(exc, "rollback_failed", False)
        self.ctx.add_error(exc)  # the workflow has returned; nothing else writes ctx now
        self.ui.progressBar_flash.setRange(0, 100)
        if rollback_failed:
            self.ui.label_rollbackWarning.setVisible(True)
            log.critical("Rollback failed: the winIDEA workspace may still point to the new files")
        if isinstance(exc, CancelledError):
            self.ui.label_step.setText("Cancelled")
            if not rollback_failed:
                return
        else:
            self.ui.label_step.setText("Failed")
        self.show_error(exc)

    def _on_flash_finished(self, key: str) -> None:
        if key == self._flash_key:
            self._flash_key = None
        if self._closing:
            return
        self._update_flash_controls()
```

```python
"""Main window: composed from the mixins, all sharing one `self.ui` built from main_window.ui.

This module owns the state the mixins share (settings, adapter, debug context, worker
registry, closing guard), the profile bar, the settings dialog and the shutdown path.
"""
from __future__ import annotations

from pathlib import Path

from PySide6.QtCore import QThreadPool
from PySide6.QtWidgets import QDialog, QMainWindow, QMessageBox

from wflash.core.debug_bundle import DebugContext
from wflash.core.errors import GitLabError, ProfileError
from wflash.core.logging_setup import get_logger, register_secret, set_verbose
from wflash.core.profile import Profile, list_profiles, load_profile
from wflash.core.settings import AppSettings, get_token, set_token
from wflash.core.winidea_adapter import WinIDEAAdapter
from wflash.gui.flash_mixin import FlashMixin
from wflash.gui.gitlab_browser import ClientFactory, GitlabBrowserMixin, default_client_factory
from wflash.gui.log_panel import LogPanelMixin
from wflash.gui.mapping_table import MappingTableMixin
from wflash.gui.settings_dialog import SettingsDialog
from wflash.gui.ui_main_window import Ui_MainWindow
from wflash.gui.workers import WorkerRegistry

log = get_logger("ui")


class MainWindow(GitlabBrowserMixin, MappingTableMixin, FlashMixin, LogPanelMixin, QMainWindow):
    def __init__(
        self,
        settings: AppSettings,
        adapter: WinIDEAAdapter,
        client_factory: ClientFactory = default_client_factory,
        log_file: Path | None = None,
        settings_path: Path | None = None,
        pool: QThreadPool | None = None,
    ) -> None:
        super().__init__()
        self.ui = Ui_MainWindow()
        self.ui.setupUi(self)
        self.settings = settings
        self.adapter = adapter
        self.log_file = log_file
        self._client_factory = client_factory
        self._settings_path = settings_path
        self.ctx = DebugContext()
        self.profile: Profile | None = None
        self._closing = False
        self._pool = pool or QThreadPool(self)
        self._workers = WorkerRegistry(self._pool, self)  # main thread, in __init__ (rule 6)

        self._init_log_panel()  # first, so the other parts' start-up is logged
        self._init_mapping_table()
        self._init_gitlab_browser()
        self._init_flash()
        self.ui.comboBox_profile.currentIndexChanged.connect(self._on_profile_selected)
        self.ui.pushButton_reloadProfiles.clicked.connect(self.reload_profiles)
        self.ui.pushButton_settings.clicked.connect(self.open_settings)

        self.reload_profiles()
        self.refresh_instances()
        self._update_flash_controls()

    # -- shared helpers -------------------------------------------------------------
    def show_error(self, exc: BaseException) -> None:
        text = str(exc)
        hint = getattr(exc, "hint", "")
        if hint:
            text += f"\n\nHint: {hint}"
        text += "\n\nUse 'Export debug bundle…' in the log panel to collect logs for support."
        title = "WFlash — rollback failed" if getattr(exc, "rollback_failed", False) else "WFlash error"
        QMessageBox.critical(self, title, text)

    def _save_settings(self) -> None:
        try:
            self.settings.save(self._settings_path)
        except OSError as exc:
            log.warning("Cannot save settings: %s", exc)

    # -- profiles -------------------------------------------------------------------
    def reload_profiles(self, *_args) -> None:
        directory = self.settings.resolved_profiles_dir()
        paths = list_profiles(directory)
        combo = self.ui.comboBox_profile
        combo.blockSignals(True)
        combo.clear()
        for path in paths:
            combo.addItem(path.stem, str(path))
        if paths:
            index = next((i for i, p in enumerate(paths) if p.name == self.settings.last_profile), 0)
            combo.setCurrentIndex(index)
        combo.blockSignals(False)
        if not paths:
            log.warning("No profiles found in %s", directory)
        self._on_profile_selected()

    def _on_profile_selected(self, *_args) -> None:
        data = self.ui.comboBox_profile.currentData()
        self.profile = None
        self.clear_mapping()
        if data is None:
            self.set_gitlab_profile(None)
            self._update_flash_controls()
            return
        path = Path(data)
        try:
            profile = load_profile(path)
        except ProfileError as exc:
            log.error("%s", exc)
            self.ctx.add_error(exc)
            self.set_gitlab_profile(None)
            self.show_error(exc)
            self._update_flash_controls()
            return
        self.profile = profile
        self.ctx.profile_path = path
        self.ui.checkBox_reset.setChecked(profile.post_flash.reset)
        self.ui.checkBox_run.setChecked(profile.post_flash.run)
        self.set_gitlab_profile(profile)
        self.settings.last_profile = path.name
        self._save_settings()
        log.info("Profile loaded: %s (%s)", profile.name, path)
        self._update_flash_controls()

    # -- settings -------------------------------------------------------------------
    def open_settings(self, *_args) -> None:
        if self.flash_active() or self.gitlab_busy():
            return
        dialog = SettingsDialog(self.settings, get_token(self.settings.gitlab_url) or "", self)
        accepted = dialog.exec() == QDialog.DialogCode.Accepted
        if dialog.cache_cleared:
            self.clear_mapping()  # the loaded artifact's files are gone
        if not accepted:
            return
        self.settings = dialog.result_settings()
        token = dialog.result_token()
        if token and self.settings.gitlab_url:
            register_secret(token)
            try:
                set_token(self.settings.gitlab_url, token)
```

```python
        if self.flash_active() and not self._closing:
            answer = QMessageBox.question(
                self,
                "WFlash",
                "A flash is in progress. Cancel it (the previous workspace paths will be restored) and quit?",
```

```python
"""WFlash entry point: parse args, set up logging and crash hooks, start the GUI."""
from __future__ import annotations

import argparse
import sys
import threading

from PySide6.QtCore import QTimer
from PySide6.QtWidgets import QApplication, QMessageBox

from wflash import __version__
from wflash.core.errors import WFlashError
from wflash.core.logging_setup import get_logger, setup_logging
from wflash.core.settings import AppSettings
from wflash.core.winidea_adapter import create_adapter

SMOKE_CLOSE_MS = 1500


def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
    parser = argparse.ArgumentParser(prog="wflash", description="Flash ECU via winIDEA from GitLab artifacts")
    parser.add_argument(
        "--adapter",
        choices=["real", "fake"],
        default="real" if sys.platform == "win32" else "fake",
        help="winIDEA adapter (default: real on Windows, fake elsewhere)",
    )
    parser.add_argument("--verbose", action="store_true", help="Log every winIDEA call")
    parser.add_argument("--smoke", action="store_true", help="Start, then close the window after 1.5 s (launch check)")
    return parser.parse_args(argv)


def install_excepthooks() -> None:
    log = get_logger("crash")

    def excepthook(exc_type, exc, tb) -> None:
        if issubclass(exc_type, KeyboardInterrupt):
            sys.__excepthook__(exc_type, exc, tb)
            return
        log.critical("Unhandled exception", exc_info=(exc_type, exc, tb))
        # A dialog only from the GUI thread; anywhere else the log entry is the report.
        if QApplication.instance() is not None and threading.current_thread() is threading.main_thread():
            QMessageBox.critical(
                None,
                "WFlash crashed",
                f"{exc_type.__name__}: {exc}\n\nDetails are in the log. Use 'Export debug bundle…' to send them.",
            )

    def thread_excepthook(args: threading.ExceptHookArgs) -> None:
        name = args.thread.name if args.thread is not None else "?"
        log.critical(
            "Unhandled exception in thread %s", name, exc_info=(args.exc_type, args.exc_value, args.exc_traceback)
        )

    sys.excepthook = excepthook
    threading.excepthook = thread_excepthook


def main(argv: list[str] | None = None) -> int:
    args = parse_args(argv)
    settings = AppSettings.load()
    log_file = setup_logging(verbose=args.verbose or settings.verbose)
    log = get_logger("main")
    log.info("WFlash %s starting (adapter=%s, log=%s)", __version__, args.adapter, log_file)
    install_excepthooks()
    app = QApplication.instance() or QApplication(sys.argv[:1])
    app.setApplicationName("WFlash")

    try:
        adapter = create_adapter(args.adapter)
    except WFlashError as exc:
        log.error("%s", exc)
        QMessageBox.critical(None, "WFlash", f"{exc}\n\n{exc.hint}")
        return 1

    from wflash.gui.main_window import MainWindow

    window = MainWindow(settings, adapter, log_file=log_file)
    window.show()
    if args.smoke:
        # close(), not app.quit(): the normal shutdown path (closeEvent) must run.
        QTimer.singleShot(SMOKE_CLOSE_MS, window.close)
    code = app.exec()
    log.info("WFlash exiting (code %s)", code)
    return code
```

```python
# Qt messages that mean a threading bug. Any of them fails the run.
THREADING_PATTERNS = (
    "QThread: Destroyed while thread",

CANCEL_DELAYS_S = (0.0, 0.005, 0.02, 0.06, 0.15, 0.4)
NEW_APP_SUFFIX = "App.s3"


class DropsMidTransfer(FakeWinIDEAAdapter):
    """Connection drops at 30 % of the download; winIDEA is back for the rollback."""

    def download(self, progress, cancel, timeout_s):
        progress(30, "Programming external flash (fake)")
        raise WinIDEAError("Connection to winIDEA lost during download")


class DropsAndStaysDown(DropsMidTransfer):
    """Connection drops mid-transfer and never comes back: the rollback must fail visibly."""

    lost = False

    def download(self, progress, cancel, timeout_s):
        self.lost = True
        super().download(progress, cancel, timeout_s)

    def set_program_path(self, name, path):
        if self.lost:
            raise WinIDEAError("Connection to winIDEA lost")
        super().set_program_path(name, path)

    def set_symbol_path(self, name, path):
        if self.lost:
            raise WinIDEAError("Connection to winIDEA lost")
        super().set_symbol_path(name, path)


class Stress:
    def __init__(self, workdir: Path, log_file: Path, iterations: int) -> None:
        self.workdir = workdir
        self.log_file = log_file
        self.iterations = iterations
        self.checkpoints = 0
        self.failures: list[str] = []
        self.qt_problems: list[str] = []
        self.qt_other: list[str] = []
        self.dialogs: list[tuple[str, str]] = []
        self.questions: list[str] = []
        self.answer = QMessageBox.StandardButton.Yes
        self._window_count = 0

    # -- infrastructure ---------------------------------------------------------------
    def check(self, condition: bool, label: str) -> bool:
        self.checkpoints += 1
        if not condition:
            self.failures.append(label)
            print(f"  FAIL: {label}", flush=True)
        return condition

    def pump(self, seconds: float) -> None:
        # Never app.quit() to end a wait (stress-test trap 1): just process events.
        deadline = time.monotonic() + seconds
        while True:
            QApplication.processEvents()
            if time.monotonic() >= deadline:
                return
            time.sleep(0.002)

    def pump_until(self, predicate, timeout_s: float) -> bool:
        deadline = time.monotonic() + timeout_s
        while not predicate():
            if time.monotonic() >= deadline:
                return False
            QApplication.processEvents()
            time.sleep(0.002)
        return True

    def new_window(self, adapter, session: FakeGitLabSession | None = None, download_s: int | None = None):
        self._window_count += 1
        folder = self.workdir / f"window{self._window_count}"
        profiles = write_profiles(folder / "profiles", download_s)
        settings = AppSettings(profiles_dir=str(profiles), cache_dir=str(folder / "cache"))
        window = MainWindow(
            settings,
            adapter,
            client_factory=SessionClientFactory(session or FakeGitLabSession()),
            log_file=self.log_file,
            settings_path=folder / "settings.json",
        )
        window.resize(1280, 820)
        window.show()
        self.check(
            self.pump_until(lambda: window.ui.comboBox_instance.count() == 1, 5.0),
            f"window{self._window_count}: fake winIDEA instance listed",
        )
        return window

    def artifact(self, name: str) -> Path:
        return make_artifact_tree(self.workdir / f"artifact_{name}")

    def close_window(self, window, label: str, max_s: float = 5.0) -> None:
        t0 = time.monotonic()
        window.close()
        elapsed = time.monotonic() - t0
        self.check(elapsed < max_s, f"{label}: close() took {elapsed:.2f}s (deadlock?)")
        self.check(window._workers.running_keys() == [], f"{label}: no worker left running after close")
        self.check(window.log_handler not in logging.getLogger("wflash").handlers, f"{label}: log handler detached")
        window.deleteLater()
        self.pump(0.05)

    def wait_step(self, window, text: str, timeout_s: float) -> bool:
        return self.pump_until(lambda: window.ui.label_step.text() == text, timeout_s)

    def wait_flash_idle(self, window, timeout_s: float = 10.0) -> bool:
        return self.pump_until(lambda: not window.flash_active(), timeout_s)

    def load_artifact_via_gitlab(self, window, label: str) -> bool:
        window.refresh_gitlab()
        # The refs -> pipelines chain keeps gitlab_busy() true until the list is final.
        ok = self.pump_until(
            lambda: not window.gitlab_busy() and window.ui.listWidget_pipelines.count() == 1, 5.0
        )
        if ok:
            window.ui.listWidget_pipelines.setCurrentRow(0)
            ok = self.pump_until(lambda: window.ui.listWidget_jobs.count() == 1, 5.0)
        if ok:
            window.ui.listWidget_jobs.setCurrentRow(0)
            window.download_selected_artifact()
            ok = self.pump_until(window.mapping_complete, 10.0)
        if ok:
            ok = self.pump_until(lambda: not window.gitlab_busy(), 5.0)
        return self.check(ok, f"{label}: GitLab browse -> download -> mapping complete")

    # -- sections ---------------------------------------------------------------------
    def section_flash(self) -> None:
        for i in range(self.iterations):
            label = f"flash[{i}]"
            adapter = FakeWinIDEAAdapter(download_seconds=0.3)
            window = self.new_window(adapter)
            if not self.load_artifact_via_gitlab(window, label):
                self.close_window(window, label)
                continue
            self.dialogs.clear()

            window.start_flash()
            self.check(self.wait_step(window, Step.DONE.value, 10.0), f"{label}: flash reached Done")
            self.check(self.wait_flash_idle(window), f"{label}: flash worker released")
            self.check(adapter.programs["App"].endswith(NEW_APP_SUFFIX) and adapter.programs["App"] != OLD_APP,
                       f"{label}: App path points to the artifact")
            self.check(adapter.target_state == "halted", f"{label}: target halted after reset")

            adapter.download_seconds = 3.0
            window.start_flash()
            self.check(self.wait_step(window, Step.DOWNLOAD.value, 5.0), f"{label}: second flash downloading")
            window.cancel_flash()
            self.check(self.wait_step(window, "Cancelled", 5.0), f"{label}: cancelled flash settled")
            self.check(self.wait_flash_idle(window), f"{label}: cancelled worker released")
            self.check(adapter.programs["App"] != OLD_APP,
                       f"{label}: cancel restored the paths of before this flash (the first flash's)")
            self.check(adapter.connected_to is None, f"{label}: disconnected after cancel")

            adapter.download_seconds = 1.0
            window.start_flash()
            levels = window.ui.comboBox_logLevel
            for n, size in enumerate(((800, 600), (1600, 1000), (1024, 700), (1280, 820))):
                window.resize(*size)
                levels.setCurrentIndex(n % levels.count())
                self.pump(0.05)
            self.check(self.wait_step(window, Step.DONE.value, 10.0), f"{label}: flash with resize/filter reached Done")
            self.check(self.wait_flash_idle(window), f"{label}: third worker released")
            self.check(self.dialogs == [], f"{label}: no error dialog in the happy paths: {self.dialogs}")
            self.close_window(window, label)

    def section_rollback(self) -> None:
        originals_programs = {"App": OLD_APP}
        originals_apps = {"CM7_0": OLD_CM7_0, "CM7_1": OLD_CM7_1}
        cases = [
            # label, adapter, profile download_s, expected rollback_failed
            ("missing entry", FakeWinIDEAAdapter(download_seconds=0.2, programs={"Other": OLD_APP}), None, False),
            ("set path refused", FakeWinIDEAAdapter(download_seconds=0.2, fail_on={"set_path"}), None, True),
            ("download fails at 50%", FakeWinIDEAAdapter(download_seconds=0.4, fail_on={"download"}), None, False),
            ("download timeout", FakeWinIDEAAdapter(download_seconds=3.0), 1, False),
            ("connection dropped mid-transfer", DropsMidTransfer(download_seconds=0.2), None, False),
            ("connection dropped for good", DropsAndStaysDown(download_seconds=0.2), None, True),
        ]
        for name, adapter, download_s, rollback_failed in cases:
            label = f"rollback[{name}]"
            programs_before = dict(adapter.programs)
            window = self.new_window(adapter, download_s=download_s)
            window.on_artifact_ready(self.artifact(name.replace(" ", "_")), f"job #{JOB_ID}")
            self.dialogs.clear()
            window.start_flash()
            self.check(self.wait_step(window, "Failed", 10.0), f"{label}: flash failed")
            self.check(self.wait_flash_idle(window), f"{label}: worker released")
            self.check(len(self.dialogs) == 1, f"{label}: exactly one error dialog, got {len(self.dialogs)}")
            self.check(adapter.connected_to is None, f"{label}: disconnected")
            warning_shown = window.ui.label_rollbackWarning.isVisibleTo(window)
            self.check(warning_shown == rollback_failed, f"{label}: rollback warning shown={warning_shown}")
            if rollback_failed and self.dialogs:
                self.check("ROLLBACK FAILED" in self.dialogs[0][1], f"{label}: dialog says ROLLBACK FAILED")
            if name == "connection dropped for good":
                self.check(adapter.programs["App"] != OLD_APP, f"{label}: (expected) App still points to the new file")
            else:
                self.check(adapter.programs == programs_before, f"{label}: program paths back to the originals")
                if name != "missing entry":
                    self.check(adapter.programs == originals_programs, f"{label}: App == original")
                self.check(adapter.applications == originals_apps, f"{label}: symbol paths back to the originals")
            self.close_window(window, label)

    def section_gitlab(self) -> None:
        session = FakeGitLabSession()
        window = self.new_window(FakeWinIDEAAdapter(), session)
        for i in range(5):
            window.refresh_gitlab()
            self.pump(0.01)
        self.check(self.pump_until(lambda: not window.gitlab_busy(), 5.0), "gitlab: repeated refreshes settled")
        self.check(window.ui.comboBox_ref.count() == 2, "gitlab: refs listed once (stale results dropped)")
        self.check(self.load_artifact_via_gitlab(window, "gitlab"), "gitlab: browse to artifact")

        window.download_selected_artifact()
        window.download_selected_artifact()  # double-click: second refused
        self.check(self.pump_until(lambda: not window.gitlab_busy(), 5.0), "gitlab: cached download settled")
        self.check(session.count(f"/jobs/{JOB_ID}/artifacts") == 1, "gitlab: one network download, then cache")

        self.dialogs.clear()
        for status, needle in ((401, "expired"), (403, "access"), (404, "expired")):
            session.fail_status = status
            window.refresh_gitlab()
            ok = self.pump_until(lambda: len(self.dialogs) == 1, 5.0)
            self.check(ok and f"HTTP {status}" in self.dialogs[0][1] and needle in self.dialogs[0][1],
                       f"gitlab: HTTP {status} shows its specific hint")
            self.pump_until(lambda: not window.gitlab_busy(), 5.0)
            self.dialogs.clear()
        session.fail_status = None
        session.connection_error = True
        window.refresh_gitlab()
        ok = self.pump_until(lambda: len(self.dialogs) == 1, 5.0)
        self.check(ok and "Cannot reach GitLab" in self.dialogs[0][1], "gitlab: connection error reported")
        session.connection_error = False
        self.pump_until(lambda: not window.gitlab_busy(), 5.0)
        self.dialogs.clear()
        self.close_window(window, "gitlab")

        # Cancel an artifact download: nothing loaded afterwards.
        slow = FakeGitLabSession(chunk_delay_s=0.02)
        window = self.new_window(FakeWinIDEAAdapter(), slow)
        window.refresh_gitlab()
        self.pump_until(lambda: window.ui.listWidget_pipelines.count() == 1, 5.0)
        window.ui.listWidget_pipelines.setCurrentRow(0)
        self.pump_until(lambda: window.ui.listWidget_jobs.count() == 1, 5.0)
        window.ui.listWidget_jobs.setCurrentRow(0)
        window.download_selected_artifact()
        self.pump_until(lambda: window.ui.progressBar_artifact.value() > 0, 5.0)
        window.cancel_artifact_download()
        self.check(self.pump_until(lambda: not window.gitlab_busy(), 5.0), "gitlab: cancelled download settled")
        self.check(not window.mapping_rows(), "gitlab: no artifact loaded after cancel")
        self.check(self.dialogs == [], "gitlab: cancel shows no error dialog")
        self.close_window(window, "gitlab-cancel")

        # Window closed mid-fetch / mid-download at several delays.
        for delay in CANCEL_DELAYS_S[:5]:
            fetch = FakeGitLabSession(delay_s=0.3)
            window = self.new_window(FakeWinIDEAAdapter(), fetch)
            window.refresh_gitlab()
            self.pump(delay)
            self.close_window(window, f"gitlab: closed {delay * 1000:.0f} ms into a fetch", max_s=3.0)
            self.check(window.ui.comboBox_ref.count() == 0, f"gitlab: nothing shown after close at {delay}s")
        for delay in (0.0, 0.05, 0.2):
            dl = FakeGitLabSession(chunk_delay_s=0.02)
            window = self.new_window(FakeWinIDEAAdapter(), dl)
            window.refresh_gitlab()
            self.pump_until(lambda: window.ui.listWidget_pipelines.count() == 1, 5.0)
            window.ui.listWidget_pipelines.setCurrentRow(0)
            self.pump_until(lambda: window.ui.listWidget_jobs.count() == 1, 5.0)
            window.ui.listWidget_jobs.setCurrentRow(0)
            window.download_selected_artifact()
            self.pump(delay)
            self.close_window(window, f"gitlab: closed {delay * 1000:.0f} ms into a download", max_s=3.0)
            self.check(not window.mapping_rows(), f"gitlab: no artifact loaded after close at {delay}s")
        self.check(self.dialogs == [], f"gitlab: no dialogs from closing windows: {self.dialogs}")

    def section_races(self) -> None:
        adapter = FakeWinIDEAAdapter(download_seconds=0.5)
        window = self.new_window(adapter)
        window.on_artifact_ready(self.artifact("races"), f"job #{JOB_ID}")
        self.dialogs.clear()
        for delay in CANCEL_DELAYS_S:
            label = f"races: cancel {delay * 1000:.0f} ms after Flash"
            before = dict(adapter.programs)
            window.start_flash()
            self.pump(delay)
            window.cancel_flash()
            window.cancel_flash()  # double Cancel
            self.check(self.wait_flash_idle(window), f"{label}: settled")
            final = window.ui.label_step.text()
            self.check(final in ("Cancelled", Step.DONE.value), f"{label}: final state {final!r}")
            if final == "Cancelled":
                self.check(adapter.programs == before, f"{label}: paths restored")
            self.check(adapter.connected_to is None, f"{label}: disconnected")
        self.check(self.dialogs == [], f"races: cancels show no error dialog: {self.dialogs}")

        downloads = adapter.calls.count("download")
        window.start_flash()
        window.start_flash()  # double Flash
        running = [k for k in window._workers.running_keys() if k.startswith("flash")]
        self.check(len(running) == 1, f"races: double Flash runs one worker, got {running}")
        try:
            window.export_bundle(self.workdir / "bundle_during_flash")
            refused = False
        except RuntimeError:
            refused = True
        self.check(refused, "races: debug bundle export refused while flashing")
        self.check(self.wait_step(window, Step.DONE.value, 10.0), "races: double-Flash run completed")
        self.wait_flash_idle(window)
        self.check(adapter.calls.count("download") == downloads + 1, "races: exactly one download for double Flash")
        self.close_window(window, "races")

        # Window closed mid-download: rollback finished before close() returns.
        adapter = FakeWinIDEAAdapter(download_seconds=10.0)
        window = self.new_window(adapter)
        window.on_artifact_ready(self.artifact("close"), f"job #{JOB_ID}")
        window.start_flash()
        self.check(self.wait_step(window, Step.DOWNLOAD.value, 5.0), "races: long flash downloading")
        self.questions.clear()
        self.close_window(window, "races: closed mid-download", max_s=3.0)
        self.check(len(self.questions) == 1, "races: close asked for confirmation once")
        self.check(adapter.programs["App"] == OLD_APP, "races: close rolled back App")
        self.check(adapter.connected_to is None, "races: close disconnected")

        # Closed during the GitLab fetch, before any flash worker exists.
        window = self.new_window(FakeWinIDEAAdapter(), FakeGitLabSession(delay_s=0.4))
        window.refresh_gitlab()
        self.pump(0.05)
        self.check(not window.flash_active(), "races: no flash worker before close")
        self.close_window(window, "races: closed during GitLab fetch", max_s=3.0)

    def section_secrets(self) -> None:
        window = self.new_window(FakeWinIDEAAdapter(download_seconds=0.1))
        window.ui.comboBox_logLevel.setCurrentIndex(0)  # DEBUG: show everything
        log.info("token in a message: %s", TOKEN)
        log.error("request headers {'PRIVATE-TOKEN': '%s'}", TOKEN)
        log.debug("url https://gitlab.example.com/api/v4/projects?private_token=%s", TOKEN)
        window.ctx.add_error(RuntimeError(f"authentication failed for {TOKEN}"))
        self.pump(0.2)
        panel = window.log_visible_text()
        self.check(TOKEN not in panel, "secrets: token absent from the log panel")
        self.check("***" in panel, "secrets: panel shows the masked token")
        for handler in logging.getLogger("wflash").handlers:
            handler.flush()
        file_text = self.log_file.read_text(encoding="utf-8")
        self.check(TOKEN not in file_text, "secrets: token absent from the log file")
        self.check("token in a message: ***" in file_text, "secrets: log file has the masked line")
        bundle = window.export_bundle(self.workdir / "bundle")
        with zipfile.ZipFile(bundle) as zf:
            contents = {name: zf.read(name).decode("utf-8", "replace") for name in zf.namelist()}
        leaked = [name for name, text in contents.items() if TOKEN in text]
        self.check(leaked == [], f"secrets: token absent from every bundle file (leaked in {leaked})")
        self.check("authentication failed for ***" in contents.get("errors.txt", ""), "secrets: bundle errors masked")
        self.close_window(window, "secrets")


SECTIONS = {
    "flash": ("full fetch->map->flash, cancel mid-download, resize + log filter while live", Stress.section_flash),
    "rollback": ("every failure branch; workspace paths restored, failed rollback shown", Stress.section_rollback),
    "gitlab": ("refresh storms, 401/403/404/connection, double-click, cancel, close mid-fetch", Stress.section_gitlab),
    "races": ("cancel at 0..400 ms, double Flash/Cancel, close mid-download / mid-fetch", Stress.section_races),
    "secrets": ("a realistic PAT through panel, log file and debug bundle", Stress.section_secrets),
}


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--list", action="store_true", help="list the sections and exit")
    parser.add_argument("--section", action="append", choices=sorted(SECTIONS), help="run only these (repeatable)")
    parser.add_argument("--iterations", type=int, default=2, help="repetitions of the flash section")
    parser.add_argument("--keep", action="store_true", help="keep the temporary work folder")
    args = parser.parse_args(argv)
    if args.list:
        for name, (description, _) in SECTIONS.items():
            print(f"{name:<9} {description}")
        return 0

    app = QApplication.instance() or QApplication([sys.argv[0]])
    workdir = Path(tempfile.mkdtemp(prefix="wflash_stress_"))
    log_file = setup_logging(log_dir=workdir / "logs")
    stress = Stress(workdir, log_file, args.iterations)

    def qt_handler(mode, context, message) -> None:
        if mode in (QtMsgType.QtWarningMsg, QtMsgType.QtCriticalMsg, QtMsgType.QtFatalMsg):
            if any(pattern in message for pattern in THREADING_PATTERNS):
                stress.qt_problems.append(message)
                print(f"  QT THREADING WARNING: {message}", flush=True)
            else:
                stress.qt_other.append(message)

    def excepthook(exc_type, exc, tb) -> None:
        text = "".join(traceback.format_exception(exc_type, exc, tb))
        stress.failures.append(f"uncaught exception: {text}")
        print(f"  UNCAUGHT: {text}", flush=True)

    def thread_excepthook(hook_args) -> None:
        excepthook(hook_args.exc_type, hook_args.exc_value, hook_args.exc_traceback)

    def unraisablehook(unraisable) -> None:
        stress.failures.append(f"unraisable: {unraisable.exc_value!r} in {unraisable.object!r}")

    previous_handler = qInstallMessageHandler(qt_handler)
    sys.excepthook = excepthook
    threading.excepthook = thread_excepthook
    sys.unraisablehook = unraisablehook

    def critical(parent, title, text, *rest):
        stress.dialogs.append((title, text))
        return QMessageBox.StandardButton.Ok

    def question(parent, title, text, *rest):
        stress.questions.append(text)
        return stress.answer

    QMessageBox.critical = staticmethod(critical)
    QMessageBox.warning = staticmethod(critical)
    QMessageBox.information = staticmethod(lambda *a, **k: QMessageBox.StandardButton.Ok)
    QMessageBox.question = staticmethod(question)

    selected = args.section or list(SECTIONS)
    started = time.monotonic()
    for name in selected:
        print(f"== {name}: {SECTIONS[name][0]}", flush=True)
        t0 = time.monotonic()
        try:
            SECTIONS[name][1](stress)
        except Exception:
            stress.failures.append(f"section {name} raised:\n{traceback.format_exc()}")
            print(traceback.format_exc(), flush=True)
        print(f"   {name} done in {time.monotonic() - t0:.1f}s", flush=True)

    stress.pump(0.3)  # let late queued signals arrive while the handlers still listen
    stress.check(workers._ABANDONED == [], f"no worker was abandoned: {[w.key for w in workers._ABANDONED]}")
    stray = [t.name for t in threading.enumerate()
             if t is not threading.main_thread() and not isinstance(t, threading._DummyThread)]
    stress.check(stray == [], f"no Python worker threads left: {stray}")
    qInstallMessageHandler(previous_handler)
    close_file_handler()
    del app

    passed = not stress.failures and not stress.qt_problems
    print(f"CHECKPOINTS={stress.checkpoints} FAILED={len(stress.failures)} "
          f"QT_THREADING_WARNINGS={len(stress.qt_problems)} OTHER_QT_WARNINGS={len(stress.qt_other)} "
          f"TIME={time.monotonic() - started:.1f}s")
    for failure in stress.failures:
        print(f"  - {failure.splitlines()[0]}")
    for message in sorted(set(stress.qt_other))[:5]:
        print(f"  other Qt warning (not a failure): {message}")
    print(f"STRESS_RESULT={'PASS' if passed else 'FAIL'}")
    if passed and not args.keep:

    else:
        print(f"work folder kept: {workdir}")
    return 0 if passed else 1


if __name__ == "__main__":
    raise SystemExit(main())
```
